# 映源播放适配规则

本仓库仅存放经过维护者测试、签名发布的播放适配规则与说明，不包含 App 源码、签名私钥、账户凭证或用户数据。

## 使用

安装映源 1.16.0（构建 40）或更新版，在红果首页右上角打开“播放适配更新”；在线播放出错时也可点“检查播放修复”。App 直接匿名读取此仓库，无需 GitHub Token 或自建服务器。

- 当前规则：[`hongguo/stable.json`](hongguo/stable.json)
- 历史签名版本：[`hongguo/versions/`](hongguo/versions/)
- 公开读取地址：<https://raw.githubusercontent.com/nuvora-f44c84/yingyuan-playback-rules/main/hongguo/stable.json>

首次发布的 2026.10.23.1 是与 App 内置规则相同的基线，因此不会提示为新补丁。

## 安全与范围

规则使用 ES256 / P-256 + SHA-256 签名，App 固定信任公钥，并检查版本、引擎兼容性及防重放序号。通过校验后仍需实际播放验证，失败可回退。签名证明发布者身份，不保证第三方服务持续可用。

此通道不执行任意远程代码，不自动执行上游 Go 源码，只支持 App 既有引擎范围内的请求参数、签名字段和响应字段适配。原生解码器、新加密算法或引擎能力变化仍需更新 App。规则不包含视频文件、播放凭证或媒体解密密钥。

维护者只应发布经过审阅与测试的已签名信封；历史版本文件保持不变，更新时添加更高序号并同步更新 stable。私钥始终保存在仓库外。
